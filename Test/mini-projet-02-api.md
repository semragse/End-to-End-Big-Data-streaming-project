# Mini-projet 02 - Appel API DummyJSON

Objectif : verifier que tu comprends comment une application Python peut recuperer des donnees depuis une API REST avant de les envoyer plus tard vers Kafka.

## Questions de comprehension

1. C'est quoi une API REST ?
2. A quoi sert une requete HTTP GET ?
3. Pourquoi l'API renvoie souvent les donnees au format JSON ?
4. C'est quoi un status code HTTP ? Donne un exemple de code qui signifie "succes".
5. Quel role jouera Python dans cette etape du projet ?
6. Pourquoi on commence par afficher les commandes avant de les envoyer dans Kafka ?
7. Quelle est la difference entre une donnee brute recue depuis l'API et une donnee nettoyee ?

## Mini-exercice

Explique avec tes mots le trajet des donnees dans cette etape :

```text
DummyJSON API
    |
    v
Python script
    |
    v
Affichage dans le terminal
```

Reponds aux questions directement dans ce fichier ou dans la conversation.
